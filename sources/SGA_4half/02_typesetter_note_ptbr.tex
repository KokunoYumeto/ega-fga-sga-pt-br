\section*{Nota do responsável pela composição eletrônica}

Esta é uma versão em \LaTeX{} de \emph{Cohomologie Étale}, de Deligne,
volume 569 de \emph{Lecture Notes in Mathematics}, Springer-Verlag. A
composição foi realizada por Daniel Miller. O código-fonte pode ser encontrado
no GitHub
(\url{https://www.github.com/dkmiller/sga4.5}). Trata-se de uma versão
essencialmente inalterada do original. A maioria das alterações é pequena; por
exemplo, empregam-se letras caligráficas em vez de letras romanas para os
feixes. A alteração mais importante é que $\Hom$ é usado para denotar o
``Hom de feixes'' e $\rHom$ o seu funtor derivado, enquanto $\rhom$ é usado
para denotar o funtor derivado do funtor Hom ordinário. Comentários ou
correções podem ser enviados para
\href{mailto:dkmiller@math.cornell.edu}{\nolinkurl{dkmiller@math.cornell.edu}}.
