# Uso da entrega final

Este pacote contém toda a árvore portuguesa corrigida e os dois PDFs.
Extraia-o e execute python scripts/build.py para recompilar;
não é necessário recuperar fontes do anexo original.

O anexo original só é necessário para reproduzir o cotejo ou
a auditoria histórica. Para esses usos, confira seu MANIFEST.tsv
e mantenha os materiais de consulta fora dos entregáveis.

O pacote não inclui anexos inalterados, escaneamentos, imagens
de inspeção, extrações ou ZIPs de checkpoints anteriores.
Consulte README.md, PDF_CHECK.md e records/PACKAGE_INVENTORY.json.
