# Candidatos a destinos incorretos de remissões

Esta é uma inspeção técnica das macros de remissão nas fontes portuguesas.
Não houve leitura do escaneamento ou alteração das fontes pelo agente de apoio.
Os trechos abaixo são candidatos para decisão do editor no cotejo sequencial;
a existência de um rótulo com o mesmo número não basta para identificar a obra
ou a exposição citada. As linhas são apenas posições aproximadas e podem mudar
durante a revisão.
