\subsection*{5.10. Casos particulares}
\subsubsection*{a) O caso não ramificado: $Y' = \emptyset$, ou seja, $Y = \emptyset$.}

Neste caso, a fórmula (5.1.1) torna-se:

\begin{equation}\tag{5.11}
\Tr_{\bZ_\ell[G],\varphi}(f'_{H^\vee_{U',X'}(\ell)}) = \sum_{x \in X^f} \nu_x(f) \mathrm{NW}_f^{G,\varphi}(x)
\end{equation}

\subsubsection*{b) O caso de multiplicidades iguais a 1: $\nu_{x'}(g_{X'}^{-1}f') = 1$ para todo $x'\in {Y'}^{g_{Y'}^{-1}f'_{Y'}}$ e todo $g\in G$.}

Neste caso, a fórmula 5.1.1 reduz-se à fórmula 5.11. Esse caso ocorre, em particular, se $\dim X = 1$ e $\nu_y(f)=1$ para todo $y\in Y$.% SOURCE_ANOMALY_PRESERVED: the certified source binds y but prints subscript x.
