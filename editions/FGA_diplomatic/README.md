# FGA — tradução com leituras do impresso

Oito exposições, oito erratas e os comentários de 1962, em unidades separadas. O conjunto não constitui uma edição diplomática estrita: algumas leituras herdadas diferem da reprodução digital do NUMDAM. A edição corrigida é apresentada separadamente.

Documento principal: [pt_BR/FGA_PTBR_PRINTED.tex](pt_BR/FGA_PTBR_PRINTED.tex). Compile com XeLaTeX a partir de `pt_BR`, em três passos. As fontes exigem TeX Gyre Pagella, Heros, Cursor e Latin Modern Math.
