# FGA — tradução com leituras do impresso

Oito exposições, oito erratas e os comentários de 1962. O conjunto contém notas editoriais em outras exposições e não constitui uma edição diplomática estrita. A exposição 212 apresenta o texto traduzido segundo o impresso, separado das notas e leituras da edição corrigida.

Documento principal: [pt_BR/FGA_PTBR_PRINTED.tex](pt_BR/FGA_PTBR_PRINTED.tex). Compile com XeLaTeX a partir de `pt_BR`, em três passos. As fontes exigem TeX Gyre Pagella, Heros, Cursor e Latin Modern Math.
